## 📌 01 / Задача и Решение

### Проблема
Абитуриенты сталкиваются с маркетинговыми буклетами вместо реального вида университетов. Настоящие фотографии кампусов, общежитий, лабораторий и библиотек разбросаны по десяткам источников, дублируются, устаревают или публикуются без подтверждения.

### Решение
**Campus Visual Profile** — быстрый AI-сервис, который по названию университета за считанные секунды (<30 сек) собирает структурированный визуальный профиль с проверенными фотографиями, категориальными фильтрами, автоматическим удалением дублей и ссылками на первоисточники.

## ⚡ 02 / Архитектура и Стек за $0

Приложение спроектировано в строгом соответствии с требованием **0 ₸ на разработку и подписки**:

* **Frontend:** React 18, TypeScript, Tailwind CSS, Lucide Icons, Leaflet (OpenStreetMap для карты кампуса).
* **Backend:** Supabase Free Tier (PostgreSQL + Edge Functions на Deno).
* **Данные и Источники:** Wikidata API, Wikimedia Commons API.
* **AI & Computer Vision:** Google Gemini 1.5 Flash API (Free Tier) — определение категорий и статуса проверки.
* **Дедупликация:** Разностный хэш (`dHash` / `blockhash`) на чистом TypeScript в Deno + SHA1.

## 🛠️ 03 / Ключевой Функционал

- [x] **Поиск и неоднозначность:** Поддержка RU/EN языков. При неоднозначности выводятся карточки совпадений на выбор.
- [x] **Категоризация:** Разделение фото по 8 категориям (*Кампус, Общежитие, Спорт, Лаборатории, Студенческая жизнь, Аудитории, Библиотеки, Город*).
- [x] **Честная неопределенность:** Фотографии разделяются на `Подтверждено` (зеленый) и `Не подтверждено` (желтый с причиной).
- [x] **Прозрачность:** Прямая ссылка на источник, автор, лицензия и дата.
- [x] **Скорость и Кэширование:** Тайм-аут обработки <30 секунд, повторная выдача из кэша — мгновенно.
